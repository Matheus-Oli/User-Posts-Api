Documentação da API User Posts

API completa para gerenciamento de usuários e posts

👥

Rotas de Usuários

  • GET /users Lista todos os usuários
  • GET /users/:id Busca um usuário por ID
  • POST /users Cria um novo usuário
  • PUT /users/:id Atualiza um usuário existente
  • DELETE /users/:id Remove um usuário
📝

Rotas de Posts

  • GET /posts Lista todos os posts
  • GET /posts/:id Busca um post por ID
  • POST /posts Cria um novo post
  • PUT /posts/:id Atualiza um post existente
  • DELETE /posts/:id Remove um post
🛠️

Tecnologias Utilizadas

  • Node.js

    Runtime JavaScript para o backend

  • Express.js

    Framework web rápido e minimalista

  • Prisma

    ORM moderno para banco de dados

📁

Estrutura do Projeto

    Arquivos estáticos públicos
